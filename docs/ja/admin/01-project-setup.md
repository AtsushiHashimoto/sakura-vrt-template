# 管理者セットアップ：プロジェクト・ユーザー作成

管理者が **新規メンバー参加時に1回だけ** 実施する手順です。

---

## 1. プロジェクト作成

1. [さくらのクラウド コントロールパネル](https://secure.sakura.ad.jp/cloud/) にログイン
2. 左メニュー「プロジェクト」→「プロジェクトの作成」
3. 以下を入力して作成

| 項目 | 例 |
|---|---|
| プロジェクト名 | `JSPS-KibanA-2026` |
| プロジェクトコード | `JSPS-KibanA-2026`（英数字・ハイフン） |

> プロジェクト単位で課金が分離されます。メンバーのバッチやテーマごとに分けることを推奨します。

### プロジェクト名の付け方

プロジェクト名は**予算・研究費の区切りに合わせる**と、費用の帰属管理が楽になります。

| 例 | 用途 |
|---|---|
| `JSPS-KibanA-2026` | 科研費 基盤A 2026年度 |
| `JSPS-KibanB-2025` | 科研費 基盤B 2025年度 |
| `NEDO-2026` | NEDO 助成プロジェクト |
| `LabInternal-2026` | 内部予算・自主研究 |

予算年度をサフィックスに入れておくと、年度末のコスト確認・次年度プロジェクト切り替えが明確になります。

---

## 2. 料金アラート設定

1. 対象プロジェクトを選択
2. 「利用料金管理」→「アラート設定」
3. 月次上限額を設定（例：100,000円）

> H100は990円/時間。月100時間で約99,000円の目安。

---

## 3. メンバー用ユーザー作成

1. 「ユーザー」→「ユーザーの作成」
2. 以下を入力

| 項目 | 内容 |
|---|---|
| ユーザー名 | メンバーの氏名（例：`yamada-taro`）|
| メールアドレス | `{名前}@<your-domain>` |
| パスワード | 初期パスワードを設定し、本人に安全な方法で連携 |

3. 作成したユーザーにプロジェクトへのアクセスレベルを付与
   - 対象プロジェクト → 「メンバー」→「追加」
   - アクセスレベル：**作成・削除**（サーバーの起動から削除まで自分で対応できる）

---

## 4. オンボーディング・オフボーディング Issue の作成

GitHub リポジトリで以下の Issue テンプレートを使って作成します。

- **オンボーディング Issue**：メンバー開始時に作成（`.github/ISSUE_TEMPLATE/onboarding.md`）
- **オフボーディング Issue**：オンボーディング時に事前作成し、終了日をマイルストーンに設定（`.github/ISSUE_TEMPLATE/offboarding.md`）

---

## 5. ログイン情報の連携

メンバー本人に以下を安全な方法（1Password等）で共有します。

- さくらのクラウド ユーザーコード
- 初期パスワード
- プロジェクトコード
- このリポジトリの URL（`docs/ja/user/` を最初に読むよう案内）
