# さくら高火力 VRT の全体構成

研究を始める前にこのページを読んで、全体像を把握してください。

---

## VRT とは

さくらインターネットの **高火力 VRT（バート）** は、NVIDIA GPU を時間単位で使える VM 型クラウドサービスです。**石狩第1ゾーン限定**で提供されています。

| プラン | GPU | CPU | RAM | NVMe | 料金 |
|-------|-----|-----|-----|------|------|
| H100 | H100 SXM 80GB | 24コア | 240 GB | 6.9 TiB | 990円/時間 |
| V100 | V100 16GB | 4コア | 56 GB | なし | （別途確認） |

> V100 プランは 2027 年 3 月末で提供終了予定です。新規作成は 2026 年 12 月末まで。

---

## 最重要ルール：停止と削除を使い分ける

```
実験が終わった → サーバーを「停止」する（「削除」ではない）
プロジェクト終了 → サーバーを「削除」する
```

| 操作 | GPU 料金 | システムディスク（/workspace のデータ） | NVMe |
|------|---------|--------------------------------------|------|
| **停止** | **止まる** | **残る** ✅ | 消える |
| **削除** | 止まる | **消える** ❌ | 消える |

**停止すればデータは消えません。** 毎回削除する必要はありません。

## 全体構成図

```
あなたのローカル PC
│
│  SSH / VSCode Remote SSH
│
▼
┌──────────────────────────────────────────────────────┐
│ さくらのクラウド 石狩第1 DC                            │
│                                                      │
│  VRT サーバー                                         │
│  ├── システムディスク（/dev/vda）                      │
│  │   停止しても残る・削除で消える                      │
│  │   └── /workspace  ← 研究データ置き場               │
│  │       H100: NVMe が透過キャッシュとして高速化       │
│  │                                                   │
│  └── NVMe（H100 のみ・6.9 TiB）                      │
│      停止で消える（キャッシュ・Docker 用）              │
│                                                      │
│  Docker コンテナ（GHCR から pull）                    │
│  └── /workspace にマウント                           │
│                                                      │
└──────────────────────────────────────────────────────┘
         │
         │ apptainer pull（miyabi 移行時）
         ▼
   東大 miyabi（大規模実験）
```

## ストレージの使い分け

### H100 の場合

| ストレージ | 停止で | 削除で | 用途 |
|---|---|---|---|
| システムディスク → `/workspace` | **残る** ✅ | 消える | チェックポイント・実験結果 |
| NVMe スクラッチ → `/mnt/nvme` | 消える | 消える | Docker・HF/PyTorch キャッシュ |

> H100 では NVMe が `/workspace` の透過キャッシュとして自動で機能します。速度はそのまま、データはシステムディスクに残ります。

### V100 の場合

| ストレージ | 停止で | 削除で | 用途 |
|---|---|---|---|
| システムディスク → `/workspace` | **残る** ✅ | 消える | チェックポイント・実験結果・キャッシュ |

## コスト感覚

| 操作 | コスト |
|---|---|
| H100 を 1 時間使う（起動中） | 990 円 |
| H100 を 停止する | **GPU 料金ゼロ**（ディスク保管料のみ） |
| **サーバーを起動したまま 1 日放置** | **約 23,000 円** |

**使い終わったら停止してください。** 課金が止まります。

---

## ルール

- サーバー名：`{名前}` または `{名前}-{用途}`（例：`yamada`、`yamada-llm`）
- 同時起動：**1 台まで**
- 実験終了後：**サーバーを停止する**（削除はプロジェクト終了時のみ）
- コード変更：`git push` で管理（サーバーに依存しない）
