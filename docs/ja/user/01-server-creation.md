# サーバーを起動する

---

## 1. コントロールパネルにログイン

[さくらのクラウド コントロールパネル](https://secure.sakura.ad.jp/cloud/) にユーザーコードとパスワードでログイン後、管理者から指定されたプロジェクトを選択します。

---

## 2. サーバーを作成

1. 左メニュー「サーバー」→「追加」
2. 通常モード（シンプルモードをオフ）に切り替え
3. 以下を設定

### ゾーン選択

**「石狩第1ゾーン」を選択してください。** VRT プランはこのゾーンのみで提供されています。

### アーカイブ選択

「マイアーカイブ」タブを選択し、管理者が作成したベースイメージを選択します。

```
base-v1-ubuntu2404
```

### プラン選択

「高火力 VRT(GPU)プラン」→ 使用するプランを選択（H100 または V100）

### ディスク

システムディスクのサイズを指定します。**このディスクに研究データが保存されます。**

| 想定用途 | 推奨サイズ |
|---------|----------|
| コード・小規模実験 | 100 GB |
| 中規模モデル・データセット | 200〜500 GB |
| 大規模実験 | 500 GB 以上 |

> サイズは後から変更できません。多めに確保することを推奨します。

### 基本情報

| 項目 | 値 |
|---|---|
| サーバー名 | `{名前}` または `{名前}-{用途}`（例：`yamada`、`yamada-llm`）|
| SSH公開鍵 | 自分の公開鍵を登録 |

4. 「作成」をクリック

---

## 3. IP アドレスの確認

サーバー一覧から作成したサーバーの IP アドレスを確認します。

---

## 使い終わったらサーバーを「停止」する

実験が終わったらコントロールパネルからサーバーを **停止** してください。

- 停止 = GPU 料金がゼロになる。データは残る。
- **削除はプロジェクト終了時のみ行ってください。**

> 停止中は少額のディスク保管料がかかりますが、GPU 料金（990円/時間）は発生しません。

---

## 注意事項

- **同時に起動できるサーバーは 1 台まで**です
- サーバー名に日付は不要です（コントロールパネルに作成日時が記録されます）
- 停止中のサーバーを再起動する場合は「起動」ボタンを押すだけです
